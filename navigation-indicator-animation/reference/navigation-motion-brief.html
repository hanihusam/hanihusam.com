Navigation motion brief

The fixed decisions behind the two-layer navigation indicator. Return here during implementation instead of redesigning the interaction mid-code.

State model

State Active layer Preview layer
Rest Current internal route, 100% opacity Hidden
Preview another item Unchanged Target item, 55% opacity
Preview active item Unchanged Hidden to prevent stacking
Internal navigation Translate old route → new route Hide
External Substack action Unchanged Preview only

Motion values

Layer Properties Curve Duration
Preview Transform and opacity --ease-hover --duration-fast · 150ms
Active Transform and opacity --ease-in-out-quart --duration-base · 200ms

Both layers move horizontally in 40px steps, use a centered transform origin, and retarget from their current rendered position. There is no bounce, spring, keyframe, or animation queue.

Input and accessibility rules

  • Pointer entry sets a temporary preview; leaving the links clears it.
  • Only keyboard-visible focus sets a focus preview.
  • NavLink remains responsible for semantic aria-current="page".
  • Reduced motion keeps both state layers but changes duration tokens to zero.
  • The theme switcher is an action, not a destination; it never receives a persistent indicator.
  • Theme-switcher focus feedback uses :focus-visible, preventing sticky styling after pointer clicks.
Cold-recall defense:
Route truth and interaction preview have different lifetimes, so they need different layers. React chooses each target; CSS interpolates only transform and opacity.
